تشغيل المشروع داخل Docker (يثبت الحزم ويشغّل السيرفر)

متطلبات: تثبيت Docker Desktop على جهازك.

التعليمات:

1. افتح سطر الأوامر في مجلد المشروع (المجلد الذي يحتوي `package.json`).

2. شغّل الأمر التالي لبناء الحاوية وبدء التطبيق:

```bash
docker-compose up --build
```

3. افتح المستعرض على http://localhost:3000

ملاحظات:
- الحاوية ستنفّذ `npm install` داخلها وتثبت الحزم ثم تشغّل `npm start`.
- إذا أردت تشغيل في الخلفية استخدم `docker-compose up -d`.
